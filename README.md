# largechoicesampling

A first operational prototype for accept-reject sampling from very large implicit
choice sets, with a concrete route-choice example.

## Main ideas

- The full choice set is represented implicitly through a `ChoiceSpace`.
- A good set `G` is generated by best-first search.
- The remainder is represented by the unexplored search frontier.
- The proposal distribution is a mixture of:
  - an elite component on `G`, and
  - a tail component obtained by sampling a frontier state and completing it.
- Accept-reject uses a bound on the unnormalized target divided by the proposal.

## First route-choice assumptions

- directed graph,
- simple paths only,
- maximum number of links,
- utility proportional to minus total travel time.
